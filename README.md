# DnD Хоумбрю

Справочник наших кастомных материалов для D&D. Это статический сайт: HTML, JS и JSON. Отдельный сервер не нужен, сайт публикуется на GitHub Pages.

## Как запустить у себя

Дважды кликните **`start.bat`**. Откроется `http://localhost:8000`.
Нужен [Node.js](https://nodejs.org) (LTS). Если его нет, скрипт попробует Python, но тогда индексы придётся собирать вручную.

> Открывать `index.html` двойным кликом нельзя: браузер не загружает JSON со страниц `file://`.

## Для игроков: как прислать свою расу, класс или предмет

Откройте на сайте страницу **«Прислать свою запись»** (ссылка в меню слева). Там всё пошагово:
выбрать шаблон → заполнить → «Проверить» → «Скачать файл» → отправить файл владельцу сайта.

Менять сайт напрямую может только владелец, это защита от посторонних.

## Для владельца: как добавить присланный файл

1. Проверьте файл: вставьте его на странице «Прислать свою запись» и нажмите «Проверить» (заодно увидите предпросмотр).
2. Положите файл в нужную папку: раса → `data/races/`, класс → `data/classes/`, предмет → `data/items/`, заклинание → `data/spells/`.
   Картинку положите в `images/` и пропишите путь в поле `"image"`, например `"images/sea-elf.jpg"`.
3. Отправьте изменения на GitHub:
   ```bash
   git add .
   git commit -m "Добавлена раса: Морской эльф"
   git push
   ```
   Или в GitHub Desktop: отметить файлы → написать название → **Commit to main** → **Push origin**.
4. Через 1–2 минуты запись появится на сайте. Ход публикации виден во вкладке **Actions** на GitHub.
   Если там красный крестик, значит в файле ошибка: откройте запуск, там написано, в каком файле.

## Как добавить запись самому (расу, заклинание, предмет...)

1. Скопируйте `_template.json` из нужной папки в `data/<раздел>/`.
2. Переименуйте файл латиницей через дефис, например `data/races/sea-elf.json`.
   **Поле `id` внутри файла должно совпадать с именем файла.**
3. Заполните поля. Картинки кладите в `images/`.
4. Пересоберите индекс: при запущенном `start.bat` это происходит само, иначе выполните `node tools/build-index.mjs`.
5. Сделайте commit и push в GitHub. Через 1–2 минуты сайт обновится.

Если у вас нет git, файл можно добавить прямо на github.com: откройте папку и нажмите **Add file → Upload files**.

## Разделы

| Папка | Раздел |
|---|---|
| `data/classes` | Классы |
| `data/races` | Расы и происхождения |
| `data/spells` | Заклинания |
| `data/backgrounds` | Предыстории |
| `data/feats` | Черты |
| `data/bestiary` | Бестиарий |
| `data/items` | Магические предметы |

Новый раздел добавляется так: допишите его в `data/sections.json` и создайте папку `data/<id>/`. Код менять не нужно.

## Разметка контента

Поле `content` — это список блоков:

| Блок | Что это |
|---|---|
| `"Строка"` | абзац |
| `{ "title": "Заголовок", "text": "...", "blocks": [...] }` | раздел |
| `{ "feature": "Название", "text": "..." }` | особенность (золотая рамка) |
| `{ "list": ["пункт", "пункт"] }` | список |
| `{ "table": { "head": [...], "rows": [[...], ...] } }` | таблица |
| `{ "accordion": "Заголовок", "blocks": [...] }` | раскрывающийся блок (подрасы, подклассы) |
| `{ "quote": "Текст", "author": "Кто" }` | цитата |
| `{ "html": "..." }` | произвольный HTML |

`text` может быть строкой или массивом строк (по абзацу на строку).

Внутри текста работает такая разметка:

- `**жирный**`
- `*курсив*`
- `[текст](https://...)` — обычная ссылка
- `[[spells/fireball|Огненный шар]]` — ссылка на другую запись сайта

## Устройство

```
index.html, list.html, view.html   — главная, каталог и страница записи (на весь сайт)
help.html, js/help.js              — «Прислать свою запись»: шаблоны, проверка, скачивание
tools.html, js/tools.js            — инструменты: закуп характеристик, кости, сложность боя
js/core.js                         — движок: меню, форматы, рендер блоков
js/list.js                         — каталог + фильтры + поиск
js/view.js                         — страница записи
data/sections.json                 — список разделов, фильтры, поля
data/<раздел>/<id>.json            — записи
data/<раздел>/index.json           — собирается автоматически
tools/build-index.mjs              — сборщик индексов (+ проверка ошибок)
tools/serve.mjs                    — локальный сервер
.github/workflows/deploy.yml       — автопубликация на GitHub Pages
```
