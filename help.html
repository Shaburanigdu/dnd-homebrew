Как прислать свою расу, класс или предмет

Ничего устанавливать не нужно. Всё делается прямо на этой странице: выбираешь шаблон, заполняешь, нажимаешь «Проверить», скачиваешь файл и отправляешь его мне. Я проверю и добавлю на сайт.

1 Выбери, что хочешь прислать

Ниже в большом поле появится шаблон — заготовка, которую нужно заполнить.

2 Заполни шаблон

Шаблон выглядит странно, но всё просто: это пары «название поля»: «значение». Меняй только текст справа, внутри кавычек. Всё остальное не трогай.

Так правильно
"name_ru": "Морской эльф",
Так сломается
name_ru: Морской эльф
пропали кавычки и запятая
5 правил, чтобы ничего не сломать
  1. Не удаляй кавычки ", двоеточия :, запятые , и скобки { } [ ].
  2. Кавычки внутри текста пиши «ёлочками»: «Привет». Обычные " внутри текста сломают файл.
  3. Не нажимай Enter внутри текста. Нужен новый абзац — сделай новую строку в кавычках через запятую: 
    "text": [
  "Первый абзац.",
  "Второй абзац."
]
  4. После последнего пункта в списке запятой нет, после всех остальных — есть: 
    "traits": ["Полёт", "Ночное зрение", "Яд"]
  5. Поле id — короткое имя латиницей маленькими буквами через дефис, без пробелов: sea-elf, fire-sword. Его никто не увидит, оно нужно для адреса страницы.
Что значат поля
  • name_ru — название по-русски, name_en — по-английски.
  • source — откуда: CST — наша кастомная штука, HB — homebrew из интернета.
  • description — 1–2 предложения для карточки в списке.
  • traits — короткий список особенностей для карточки.
  • image — маленькая картинка для карточки в списке (её можно обрезать как удобно). gallery — нормальные картинки целиком, они показываются в самом низу страницы. Картинки просто пришли мне отдельными файлами, а эти поля можно удалить вместе со строкой.
  • content — основной текст страницы. Он состоит из блоков: "title" — заголовок раздела, "feature" — особенность в рамке, "list" — список, "table" — таблица, "accordion" — раскрывающийся блок (подрасы, подклассы). Ненужные блоки можно удалить, нужные — скопировать.
  • В тексте можно писать **жирный** и *курсив*.
  • Поле не нужно? Удали строку целиком. Главное — потом нажми «Проверить».

Текст сохраняется в браузере сам, но надёжнее сразу скачать файл (шаг 4).

3 Нажми «Проверить»

4 Скачай файл и отправь мне

Кнопка станет доступна, когда проверка пройдёт без ошибок.

Скачанный файл (например sea-elf.json) отправь мне в личку вместе с картинкой, если она есть. Я добавлю его на сайт.
